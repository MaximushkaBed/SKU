## Интеллектуальная система самоконтроля подготовки к экзаменам

Учебный проект по модулям 1–2 дисциплины «Архитектура и основы интеллектуальных информационных систем» / «Система самоконтроля подготовки к экзаменам».

Проект реализует web‑систему с базой данных и элементами интеллектуального анализа, строго опираясь на требования из документов `Модуль .txt` (Модуль 1) и `Модуль 2.txt`.

### Стек

- **Backend**: `Python`, `FastAPI`
- **БД**: `SQLite` (по умолчанию) или **MySQL** (через `phpMyAdmin`)
- **ORM**: `SQLAlchemy 2.x`
- **Аутентификация**: JWT‑токены (пароли в виде хэшей)

### Архитектура, соответствие модулям

- **Модуль 1 — архитектура ИИС**
  - Проектирована как web‑ориентированная ИИС с уровнями:
    - пользовательский интерфейс (HTTP‑API, удобный для фронтенда),
    - прикладной уровень (бизнес‑логика FastAPI),
    - уровень хранения данных (реляционная БД),
    - интеллектуальный модуль анализа (функции вычисления уровня готовности и рекомендаций).
- **Модуль 2 — система самоконтроля**
  - Реализованы сущности и связи из описанной физической модели БД:
    - `subject`, `topics`, `questions`, `answers`,
    - `users` (student/teacher/admin),
    - `tests`, `test_results`,
    - `recommendations`, `schedules`, `notifications`.
  - Реализованы базовые сценарии:
    - регистрация и авторизация пользователей;
    - создание предметов, тем, вопросов и ответов (для преподавателя/админа);
    - запуск теста студентом (быстрый / полный);
    - фиксация ответов, расчёт процента успешности;
    - генерация текстовых рекомендаций и базового плана подготовки;
    - создание записей расписания и уведомлений в БД.

Интеллектуальная часть реализована в виде вычисления «уровня готовности» и формирования рекомендаций на основе результатов теста (упрощённая ML‑логика, предусмотренная как точка расширения).

### Структура проекта

- `main.py` — точка входа FastAPI‑приложения.
- `database.py` — подключение к БД, базовый класс моделей.
- `models.py` — ORM‑модели таблиц.
- `schemas.py` — Pydantic‑схемы (DTO) для запросов/ответов.
- `auth.py` — аутентификация и управление пользователями.
- `routers/subjects.py` — предметы, темы, вопросы, ответы.
- `routers/tests.py` — запуск тестов, ответы, результаты, рекомендации.
- `routers/schedules.py` — расписание и уведомления.
- `services/analytics.py` — вычисление уровня готовности и генерация рекомендаций.

### Быстрый запуск

1. **Создать и активировать виртуальное окружение** (рекомендуется).
2. **Установить зависимости**:

```bash
pip install -r requirements.txt
```

3. **Запустить сервер**:

```bash
uvicorn main:app --reload
```

### Подключение к MySQL (phpMyAdmin)

Если у вас уже есть база MySQL, задайте переменную окружения `DATABASE_URL`.

1. Скопируйте `.env.example` в `.env` и заполните:

```bash
DATABASE_URL="mysql+pymysql://USER:PASSWORD@HOST:3306/DBNAME?charset=utf8mb4"
```

2. Запустите сервер как обычно. Таблицы создадутся автоматически (если их нет).

Важно: если в вашей MySQL базе таблицы **уже существуют**, но называются/имеют поля иначе — нужно будет подогнать `models.py` под вашу схему. В таком случае просто дайте мне экспорт структуры из phpMyAdmin (`.sql`) или список таблиц/полей.

4. **Открыть интерактивную документацию**:
- Swagger UI: `http://127.0.0.1:8000/docs`
